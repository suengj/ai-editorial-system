# Business Idea Magazine — 고정 5장 사업 아이디어 카드

SUE-1417 · 명시적으로 선택하는 시리즈 프로필. 새 서비스·DB·전역 문체 규칙이 아니다.
진입 요청: **“사업 아이디어 매거진으로 만들어줘”**, **“사업화 아이디어 카드 5장”**.
기존 `STRUCTURED-VISUAL-EXECUTION.md` §9, `SLIDES-AND-CAROUSELS.md`의
`silent_carousel`, `AI-IMAGE-GENERATION-GUIDE.md`를 필요한 범위에서 재사용한다.

## 1. 편집 목적

**스타트업 미디어 × 비즈니스 스쿨 케이스 스터디 × 시각적인 아이디어 노트**.
독자는 한 사업을 이해하고 자신이 시도할지를 생각할 수 있어야 한다.
아이디어를 세계 최초 발명이나 검증된 투자 기회로 포장하지 않는다.
실재하는 회사가 있다는 사실은 제안한 사업의 수익성·한국 시장 적합성·수요 검증이 아니다.

한 호는 아래 다섯 페이지다. 다른 콘텐츠에 이 구성을 강제하지 않는다.

| 순서 | 한 장의 역할 | 남길 내용 | 시각적 중심 |
| --- | --- | --- | --- |
| 1 표지 | 어떤 사업인지 즉시 이해 | 강한 제목 + 아이디어 한 문장 + 핵심 고객 | 잡지 표지형 대형 이미지/제목 |
| 2 돈의 흐름 | 누가 왜 돈을 내는지 | 가치 흐름, 지불 주체, 플랫폼 수익, 주요 비용 | 한 개의 명료한 흐름도 |
| 3 실제 사례 | 현실의 작동 방식 | 실제 회사/제품 + 핵심 거래 방식 + 출처 | 실자료 또는 명확히 구분한 설명용 비주얼 |
| 4 비교/심화 | 차이와 한계 발견 | 두 번째 회사의 다른 방식, 또는 첫 사례의 근거 있는 심화 | 동일한 비교 축 |
| 5 기회와 질문 | 독자의 판단 | 기회 **가설** + 주요 장애물 + 작은 실험 + 마지막 질문 | 기회 한 문장과 여백 |

마지막 문장은 **“당신이라면 이 사업을 하시겠습니까?”**.
이 CTA와 비개인적 매거진 문체는 이 시리즈에만 적용한다. Instagram의
개인 회고체/`suengj-style`/CTA 없음 기본값을 전역 수정하지 않는다.

## 2. 콘텐츠 제작 순서

1. 입력된 아이디어를 문제·대상·지불 주체·거래 방식·수익모델로 분해한다.
   기존 300개나 24개 클러스터는 **아이디어 씨앗**이지 정답이나 검증된 데이터가 아니다.
   번호 구간을 엄밀한 분류·시장 규모로 제시하지 않는다. 반복 방지는 기존 편집 이력이
   있을 때 비교하며, 없으면 중복 검사를 했다고 말하지 않는다.
2. 실제 사례를 **해당 제작 시점에 검색**한다. 제품·가격·공식 설명을 직접 읽고,
   중요한 성과 주장을 다룰 때만 독립 자료를 추가한다. 검색 결과 요약만으로 확정하지 않는다.
   두 사례를 찾지 못하면 첫 사례를 심화한다. 하나도 찾지 못하면 사례 페이지를
   꾸며내지 말고 소재를 교체하거나 보류한다.
3. 주장마다 `fact / analysis / assumption`을 구분한다. 사실은 출처에 연결하고,
   중요한 숫자는 기간·지역·단위·발행일을 함께 확인한다. 날짜 없는 문서는
   `published_at: null`, 열람일은 실제 열람일을 기록한다.
4. 다섯 페이지 원고와 이미지 역할을 작성한다. 페이지별 정보는 한 핵심 주장에
   집중하며, 사례끼리 **같은 비교 축**을 사용한다. 3·4장은 회사 소개를 반복하지 않는다.
5. 아래 compiler로 작은 실행 packet을 기존 carousel 입력으로 변환하거나, 동일
   편집·미술 감독 계약을 native 이미지 도구에 적용한다. 두 실행 경로를 구분한다.
6. 실제 이미지의 한국어·사실·가독성·일관성을 검토하고 필요한 페이지만 수정한다.
   게시와 계정 결정은 별도다. 이 가이드가 게시 허가나 일일 자동화를 만들지 않는다.

## 3. 사실과 돈을 다루는 규칙

- **거래액 ≠ 플랫폼 매출 ≠ 이익**. 고객이 낸 전체 금액을 플랫폼의 수익으로 부르지 않는다.
  정산금·수수료·결제비·고객지원/물류비 중 주요 비용을 숨기지 않는다.
- 수수료나 매출이 비공개이면 `미공개`다. 그럴듯한 비율을 기업의 실제 정책으로 쓰지 않는다.
  가상 계산은 `가정` 표기를 화면에 남기고 입력·산술을 별도 확인한다.
- 투자 유치액·가입자 수·거래량은 흑자 증거가 아니다. 출처 없는 수익성 별점은 사용하지 않는다.
- `same_model`은 핵심 거래 원리가 유사하다는 뜻이지 모든 요소가 같다는 뜻이 아니다.
  `adjacent`는 인접 사례다. 이 차이를 독자에게 보이게 남긴다.
- 4장을 같은 회사로 채우면 `deep-dive`, 다른 회사면 `compare`로 기록한다.
  첫 사례의 사실을 회사명만 바꿔 두 번째 사례로 만들지 않는다.
- **숨겨진 기회는 검증 전 가설**이다. “한국에는 없다”, “아직 아무도 안 했다”는
  검색으로 확인하지 않은 시장 공백 주장을 금지한다. 기존 국내 사업자가 있어도
  유효할 수 있는 좁은 고객·동선·품질·공급 측 마찰을 가설로 제시한다.
- 주요 사실은 카드에 간단한 출처, 캡션에 원문 URL/기준일을 둔다. 검증·지역 제한처럼
  해석을 바꾸는 조건은 캡션으로 숨기지 않고 카드에도 남긴다.
- 식품·의료·금융 등 규제 분야는 실제 실행의 주요 제약을 확인한다. “해외 서비스가
  존재하므로 국내에서 합법”으로 추론하지 않는다. 불필요한 법률 장문 대신 필요한 제약만 설명한다.

## 4. 하나의 잡지처럼 보이는 미술 감독

정본은 `business-idea-magazine.v1.json`. 기존 `editorial-minimal`을 선택하며
계정명·로고·워터마크는 추정하지 않는다. `trends.moa`나 `suengj.com`을 자동 삽입하지 않는다.

공통: 4:5, 아이보리/짙은 남색/세이지, 고정 여백·페이지 표기·타이포 역할.
색과 폰트는 같은 호뿐 아니라 다음 호에도 동일 프로필에서 출발한다. 개별 카드마다
임의로 다른 템플릿을 고르는 대신 **같은 시리즈 안에서 내부 구성만 변화**시킨다.
표지는 대담한 사진·제목, 돈의 흐름은 도식, 사례는 근거, 마지막은 여백이 중심이다.

“잡지 느낌”은 작은 상자와 장식 아이콘을 늘리라는 뜻이 아니다. 완성된 카드가
화면을 채워야 하며, 잡지가 책상에 놓인 목업·휴대폰 목업·다섯 장을 한 이미지에
붙인 contact sheet를 납품 이미지로 대신하지 않는다.

초기 문구 예산은 제목 두 줄, 짧은 본문 2–4줄 정도다. 이는 검토용 휴리스틱이며
기계적 글자 제한이 아니다. 필수 조건을 삭제하거나 폰트를 계속 줄이지 않는다.
레이아웃·문장·상세 설명의 위치를 조정하고 5장 안의 핵심 논리를 유지한다.
기존 단순 합성기는 단일 font_family를 사용하므로 역할별 서체가 실제 지원된 것처럼
보고하지 않는다. native 경로의 서체 처리는 실제 출력에서 별도 확인한다.

### 사진과 생성 이미지

실제 회사 사진/화면은 원본 bytes와 권리·출처가 확보된 경우만 사용한다.
검색에서 보였다는 사실이나 출처 표기만으로 재사용 허가를 얻었다고 판단하지 않는다.
권리가 불분명하면 원본 링크로 근거를 남기고 독립적인 설명 도식/콘셉트 비주얼로 바꾼다.

회사 화면·행사·고객·사업장 사진을 생성하여 실제 증거처럼 보여주지 않는다.
생성한 장면이 실사진으로 오인될 수 있으면 **“연출 이미지”**를 표시한다.
실제 로고가 없으면 회사명을 정확한 문자로 표기하며 가짜 로고를 만들지 않는다.
회사 사진은 생성 도구로 다시 그리지 않고 필요시 기존 합성 경로에서 보존한다.

### 두 실행 경로

- **로컬 합성:** 실제 이미지 모델은 그림 자산을 만들고, 기존 renderer가 정확한
  문구/출처/도식을 조판한다. 새 compiler는 원고를 renderer가 읽는 plan으로 바꿀 뿐이다.
- **Native 통합 생성:** 실제 native 도구로 완성 카드 생성이 가능한 환경에서는
  기존 integrated-text 정책에 따라 실행할 수 있다. 작은 한국어·도식·회사명·출처도
  실제 픽셀에서 확인한다. `native_candidate`는 로컬 compositor E2E 증거가 아니다.
  정확한 숫자·축이 핵심이면 검증된 사실 레이어를 우선하며 생성 결과를 그대로 믿지 않는다.

확보되지 않은 자산·미실행 경로는 `RENDER_REQUIRED` 또는 `NOT_RUN`으로 남긴다.
좋은 실제 이미지를 보여주는 일과 모든 자동화 경로의 인증을 혼동하지 않는다.

## 5. 작은 실행 packet과 기존 엔진 연결

새 profile axis/계정 DB/일반 리서치 엔진을 만들지 않는다.
원고·검색 자료·생성 이미지는 이 공개 저장소가 아닌 기존 콘텐츠 저장소에 둔다.
사용자가 JSON을 작성할 필요는 없다. LLM이 아래 두 파일을 만든다.

`packet.json`:
- `schema_version: "1.0.0"`, `series_id`, `request`, `series_label`, `evidence_ref`, `caption`.
- `idea`: `problem / target / payer / mechanism / revenue`.
- `money`: `value_flow / payment_flow / platform_revenue / main_cost`.
- `frames`: 순서대로 `cover / money / case-a / case-b / opportunity`.
  각 항목은 `role / headline / body / takeaway / alt_text / claim_ids`.
  사례 페이지는 `case_id`, 4장은 `case_mode: compare | deep-dive`.
  선택 `visual`은 기존 `image / generated / chart` 블록의 `ref`, 권리, 지시 필드를 사용한다.

`evidence.json`:
- `schema_version: "1.0.0"`, `as_of`.
- `sources`: `id / url / title / kind (official|independent) / published_at / checked_at`.
- `claims`: `id / kind (fact|analysis|assumption) / text / source_ids`.
- `cases`: `id / name / match (same_model|adjacent) / claim_ids`.

근거 dossier와 원고를 분리한다. 제목만 고치면서 근거 파일·경로를 매번 새로 만들지
않아야 기존 renderer의 frame-local 재사용 조건을 유지할 수 있다.
사실이 바뀌면 dossier를 갱신하고 영향받은 페이지를 다시 검토한다.

```bash
# 원고/근거 구조 점검 + 기존 carousel 입력 생성. 이미지 생성이 아님.
node scripts/compile-business-magazine.mjs --packet /content/packet.json --out /tmp/bizmag-plan

# 준비된 실제 자산을 기존 renderer로 합성. 미제공 생성자산은 완료가 아니다.
node scripts/render-carousel.mjs --plan /tmp/bizmag-plan/series.json --out /tmp/bizmag-first

# 기존 --previous 경로: 원본 및 바뀌지 않은 frame bytes의 재사용
node scripts/render-carousel.mjs --plan /tmp/bizmag-revised/series.json --previous /tmp/bizmag-first --out /tmp/bizmag-second

# CI가 아닌 수동 로컬 검사
node scripts/test-business-magazine.mjs
```

컴파일 결과: `series.json`, `editorial-sidecar.json`, `caption.md`, `generation-brief.md`.
`PLANNED_NOT_RENDERED`는 그림도, 사실 인증도, 게시 승인도 아니다.
source/claim ID 연결 검사는 인용이 실제 주장을 뒷받침한다는 의미 검증을 대체하지 않는다.
`generation-brief.md`는 native 도구/미술 감독에 전달할 전체 문맥이며, 개별 그림
자산만 생성할 때는 해당 frame의 지시와 이미지 정책만 전달한다.

## 6. 납품과 검수

납품은 개별 카드 5장, 짧은 캡션과 상세 출처, 장별 alt text.
가능한 실행 경로에서는 390px phone preview·contact sheet·출력 hash도 남긴다.
실제 없는 파일 경로/Drive URL/이미지 ID는 만들지 않는다.

검토: 표지만 보아도 아이디어가 이해되는가, 돈을 내는 사람이 보이는가,
사례 둘의 차이가 보이는가, 기회가 가설로 표시되는가, 한국어가 자연스러운가,
휴대폰에서 읽히는가, 다섯 장이 같은 잡지인가.

기본 시안은 한 세트다. 문제 있는 frame/layer만 고치고 변하지 않은 소재는 보존한다.
기계검사·작성자 검토·독립 vision 검토·사용자 수락은 서로 구분한다.
실제 게시/예약/성과분석/매일 자동 생성은 이 작업의 범위가 아니다.
