# Video style benchmark notes

This summary preserves only the public references supplied with SUE-1645; the
working benchmark input is intentionally not part of this repository. Values
marked **[P]** are starting hypotheses from that input and need frame-level
calibration before they can be treated as observed facts.

- **Narration-led motion design [S/P].** The supplied benchmark describes
  Kurzgesagt's narration-first production flow and recommends layered motion,
  restrained palettes, and morph or match-cut transitions as hypotheses.
  [Kurzgesagt production](https://kurzgesagt.org/youtube/)
- **Semantic color and progressive explanation [S/P].** The supplied notes
  cite 3Blue1Brown's public FAQ and Manim materials for a dark, role-based
  palette, then mark the detailed build-up timing as a practical hypothesis.
  [3Blue1Brown FAQ](https://www.3blue1brown.com/faq/)
- **Caption and frame constraints [P].** Hook timing, caption density,
  safe margins, scene lengths, and audio targets in these profiles are
  implementation starting values from the supplied benchmark, not claims that
  every cited creator uses those exact measurements. The validator enforces
  the declared plan contract; it does not measure encoded frames or audio.

Profile values are defaults for production planning. Source facts, rights,
accessibility, and render acceptance remain governed by their canonical
contracts and evidence.
