## 3. Root cause and contribution

Phase 0’s primary cover failure was the old composition obscuring the central source photo, with text hierarchy/spacing secondary. In the new hero B render, the unchanged photo occupies the upper 54% of the card and normal document flow ties the headline and summary into a single lower group. No image model or generated source art changed, so the observed difference comes from layout and composition.

The money card shows the limit of the first hypothesis: CSS flow can make all the original chart content readable, but the visual still has four containers. The case card benefits more from semantic two-column composition and responsive stacking. This small sample cannot establish universal quality superiority.

## 4. Quality assessment

**Technical:** A and B outputs are 1080×1350. 390px downscaled pairs are 390×488. Final HTML runs verify font load, no horizontal page overflow, and footer/content bounds at desktop and mobile; no source string or numeric claim was omitted in the money/case types. The money diagram preserves all four node texts; the JustPark type preserves all five original fact lines. Responsive outputs were visually inspected.

**Aesthetic:** Direct image review favors the HTML cover and the case-card hierarchy for this sample. The four-panel money style is mixed and remains unpromoted. Source accuracy/rights and owner taste were not re-approved here. `OWNER_AESTHETIC_REVIEW_PENDING` remains the status; no `OWNER_ACCEPTED` claim is made.

The archived A layer text, colors, order, and slots remain intact; only local paths and font faces are adapted for replay. `render_m1_additional_types.py` reuses current M1 plans, retargets only archived local source paths and resolves the current editorial profile before each A render. B uses only the archived M1 palette. Both scripts reject occupied output paths before writing; the additional-card layout checks include content/footer and sibling-element separation at desktop and mobile sizes. Existing AES code, SUE-1614 typography, SUE-1616 hybrid/native path, SUE-643 references, and SUE-646/647/648 QA separation remain authoritative.
