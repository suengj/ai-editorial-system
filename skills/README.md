# skills/

Portable Skill definitions. A Skill is an **orchestration contract**: inputs,
outputs, invariants, acceptance checks. The generator that satisfies it is a
replaceable worker and is never hardcoded here.

Admits: Skill manifests and instructions.
Rejects: vendor SDK code, credentials, model-specific hardcoding.

Format defined by AES-P2.1 (SUE-443); Skills built in AES-P2.2–P2.6.
