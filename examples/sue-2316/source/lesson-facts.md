# Lesson Facts: 반올림한 수가 같아도 실제 수는 다를 수 있다

- concept_id: `g5-2-rounding-same-rounded-different-actual`
- 대상: 5학년 2학기
- 범위: 0 이상의 정수인 사람 수. 천의 자리까지 반올림할 때는 백의 자리 숫자를 본다. 0~4이면 버리고, 5~9이면 올린다 (정수 half-up).

## 사실

### F1. A의 실제 관중 수
- 표시: 82,800명
- 읽기: 팔만 이천팔백 명
- 계산 확인: 82,800 = 82,000 + 800; 백의 자리 숫자 8이므로 83,000으로 반올림한다.

### F2. B의 실제 관중 수
- 표시: 83,200명
- 읽기: 팔만 삼천이백 명
- 계산 확인: 83,200 = 83,000 + 200; 백의 자리 숫자 2이므로 83,000으로 반올림한다.

### F3. 두 관중 수의 반올림 결과
- 표시: 82,800명 → 83,000명; 83,200명 → 83,000명
- 읽기: 팔만 이천팔백 명 → 팔만 삼천 명; 팔만 삼천이백 명 → 팔만 삼천 명
- 계산 확인: 82,800은 82,000 + 800이므로 83,000, 83,200은 83,000 + 200이므로 83,000이다.

### F4. 실제 관중 수의 차이
- 표시: 83,200명 − 82,800명 = 400명
- 읽기: 팔만 삼천이백 명 빼기 팔만 이천팔백 명은 사백 명
- 계산 확인: B − A = 83,200 − 82,800 = 400명.

### F5. 83,000으로 반올림되는 정수의 범위
- 표시: 82,500..83,499 → 83,000
- 읽기: 팔만 이천오백부터 팔만 삼천사백구십구까지 → 팔만 삼천
- 계산 확인: 83,000 − 500 = 82,500이고 83,000 + 499 = 83,499이다. 이 양 끝을 포함한 모든 정수가 83,000으로 반올림된다.

### F6. 아래쪽 경계 바로 전
- 표시: 82,499 → 82,000
- 읽기: 팔만 이천사백구십구 → 팔만 이천
- 계산 확인: 82,499 = 82,000 + 499; 백의 자리 숫자 4이므로 82,000으로 반올림한다.

### F7. 위쪽 경계
- 표시: 83,500 → 84,000
- 읽기: 팔만 삼천오백 → 팔만 사천
- 계산 확인: 83,500 = 83,000 + 500; 백의 자리 숫자 5이므로 84,000으로 반올림한다.

### F8. 오개념
- 표시: “반올림한 수가 같으면 실제 수도 같다”는 거짓.
- 읽기: “반올림한 수가 같으면 실제 수도 같다”는 거짓.
- 계산 확인: 82,800 ≠ 83,200이지만 둘 다 83,000으로 반올림된다. 실제 차이는 400이다.

## 비트

- `beat-01` 훅: “관중 수가 같은데 순위는 다르다고?” A는 82,800명, B는 83,200명이다. 여기서 같다는 것은 천의 자리까지 **반올림한 관중 수**다. (F1, F2, F3, F8)
- `beat-02` 규칙: 천의 자리까지 반올림하려면 백의 자리를 보고 0~4는 버리고 5~9는 올린다. (F1, F2, F3)
- `beat-03` 결과: A와 B는 모두 83,000명으로 반올림된다. (F1, F2, F3)
- `beat-04` 실제 차이: B − A = 400명이다. (F1, F2, F4, F8)
- `beat-05` 수직선: 82,500 / 83,000 / 83,500을 표시한다. 83,000으로 반올림되는 정수 범위는 82,500..83,499이다. (F5, F6, F7)
- `beat-06` 마무리 질문: “그럼 83,499는? 83,500은?” 답: 각각 83,000, 84,000이다. (F5, F7)
