# 반올림한 수가 같아도 실제 수는 다를 수 있다

대상은 초등학교 5학년 어린이. 천의 자리까지 반올림한 관중 수가 같아도 실제 관중 수와 차이는 다를 수 있음을 알려 준다. 사람 수는 0 이상의 정수다.

세로 화면 1080×1920, 목표 60초. 수직선과 비교를 한 단계씩 보여 주고 설명과 자막을 맞춘다. 글꼴 조합은 pretendard-pretendard, 장르 프리셋은 math-lecture다. 여섯 화면은 질문, 규칙, 결과, 실제 차이, 범위, 마무리 질문 순서다.

**BLOCKED — 내레이션 근거:** 제안된 어린이용 문장은 원문 바이트 구절과 일치하지 않는다. 현재 v2 검증기는 각 문장이 순서대로 인용한 검증 구절을 공백으로 이은 문자열과 정확히 같아야 하며, 바꾸어 쓴 문장이나 승인 문구를 허용하는 경로가 없다. 따라서 대본은 검토용 후보이며 TTS·렌더 준비 완료가 아니다. 원문은 변경하지 않았다. 권리 확인, 대본 승인, 실제 음성 길이와 자막 정렬도 미완료다. 등록된 영상 목적지가 없어 공통 입구 READY 영수증은 없다.
