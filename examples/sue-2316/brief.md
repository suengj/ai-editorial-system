# 반올림한 수가 같아도 실제 수는 다를 수 있다

대상은 초등학교 5학년 어린이. 천의 자리까지 반올림한 관중 수가 같아도 실제 관중 수와 차이는 다를 수 있음을 알려 준다. 사람 수는 0 이상의 정수다. 가 경기장 (A)은 82,800명, 나 경기장 (B)은 83,200명이다.
